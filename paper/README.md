# JOSS paper draft

This directory holds the draft paper for a planned submission to the
Journal of Open Source Software (https://joss.theoj.org).

Submission is deliberately deferred: JOSS review criteria require at
least six months of public development history and evidence of use in
research, so the planned submission window is 2027-02 or later, after
the method paper's peer review concludes. The draft lives in the
repository from day one because that public history is part of what JOSS
reviews.

Author-list note: the software author is listed; co-authorship for
supervisory contributions to the underlying method study is to be agreed
before submission.

Bibliography note: entries with "and others" mark author lists still to
be completed verbatim from the cited papers before submission; titles,
journals, volumes and pages are taken from the method paper's verified
reference list.
